<span class="scroll-page">第 1 页</span>

在搜集了在瘟疫之地的骑士团弟兄们的情报以后，我们对现在本行省居民的分类大感困惑。首先，这个分类是由雅克·科尔上校司令所写。按照它的规定，许多居民既不属于人类，也不属于动物。

<span class="scroll-page">第 2 页</span>

流亡者是被灰色死神所感染的人。对他们的性质，我们知之甚少。对他们的起源和能量，有相反的说法。在瘟疫之地以外，很少会见到他们。皇帝法令判决，消灭所有被灰色死神所感染的人。但是，按照我们骑士团领主的秘密命令，我们的弟兄护送这些可怜的灵魂至瘟疫之地。愿神光怜悯他们。

<span class="scroll-page">第 3 页</span>

恐狼是上古野兽，被异教徒保留下来，以保护他们的森林和猎杀帝国探马。它们比一般的狼大许多，而且因为必须同被咒者争夺肉类的缘故，它们胃口惊人。

<span class="scroll-page">第 4 页</span>

麻疯病人是被灰色死神折磨的城乡居民。他们的身体和灵魂已经变形，它们的头脑已经被毁，现在处于疯狂状态，攻击任何尚未得病的人。瘟疫之神的仆人使用这些不幸之人，作为反对帝国军队的武器。

<span class="scroll-page">第 5 页</span>

被咒者是死亡后被再生的麻疯病人。在瘟疫的起初，麻风病人像其他病人一样被下葬。但是它们在下葬后会自己把自己的尸体给挖出来，这吓坏了无辜的人们。现在，再没有人去埋葬这些坏蛋，可是他们仍然在瘟疫之地游走。我们认为这些被咒者失去了所有的感觉，是灰色死神疾病发展的最后阶段。

<span class="scroll-page">第 6 页</span>

被咒骑士是为了换取灵魂不灭和更大的身体能量，而甘愿接受瘟疫之神所传疾病的帝国勇士。这些怪物的良知需要打个问号。我们对他们的唯一可靠的认识，是他们对人血和害人有着无法满足的欲望，这些东西会给瘟疫勇士带来无法描述的狂喜。

<span class="scroll-page">第 7 页</span>

被咒圣殿骑士是赫拉特神殿保镖的邪恶躯壳，是为了换取灵魂不灭和更大的身体能量，而甘愿接受瘟疫之神所传疾病的骑士。他们在战场传播死亡和恐怖，享受敌人的死亡。

<span class="scroll-page">第 8 页</span>

哭泣女巫是哀哭丈夫的寡妇，她们的悲惨灵魂永远被灰色死神所困。哭泣女巫在侍奉瘟疫之神中找到了特别安慰。如果您听到远处的女巫哭泣，为了最好绕道走，而不是冒险去打扰她们。您也要小心，不要中了她们的诡计。女巫可能在用狂叫吸引所有周边的被咒者之前，会引诱粗心的旅行者。

<span class="scroll-page">第 9 页</span>

夜游神是夜晚出现的精灵，专喝活人的血。人类无法杀掉夜游神，但是火可以驱离它一段时间。另外，夜游神总是避免一些能量之地 - 据信是因为那里有大量灵魂再生之故。

<span class="scroll-page">第 10 页</span>

麻疯战士是被弃骑士团的步兵，他们在灵魂上和肉体上，堕落到了唯指挥员的马首是瞻、对周遭事物麻木不仁的程度。被弃骑士团的战士随时准备杀掉那些尚未接受瘟疫之神诅咒的人。

<span class="scroll-page">第 11 页</span>

被附身者是被弃骑士团的俘虏，从死亡中还魂。那些被当作祭品献给瘟疫之神的人的身体，有时可以还魂。被鬼附者的行为可以预测，但是他们有着野生动物般的力量和顽固。与同样生活于地面之上的被咒者不同，被鬼附者不见阳光，这使得他们肤色惨白。

<span class="scroll-page">第 12 页</span>

被弃者是自甘堕落的破碎机骑士团武士。按照加入破碎机骑士团的奉献礼的要求，他们每个人都杀掉几个不叛变帝国、或是按照瘟疫之神的强壮标准不能参加新骑士团的军中弟兄。

<span class="scroll-page">第 13 页</span>

亵渎者是向瘟疫之神宣誓忠诚的前破碎机骑士团的圣殿武士。他们在其领主名义下的狂热和残忍，使得自己成为了邪恶的军中弟兄的榜样。他们是破碎机骑士团的骨干。任何碰到亵渎者的人，要么投降，要么被杀。

<span class="scroll-page">第 14 页</span>

瘟疫之卵是瘟疫之神的仆人，传播灰色死神，感染它们能够接触到的每个人。它们的接触不仅有毒，还很厉害。

<span class="scroll-page">第 15 页</span>

狂热者是瘟疫之神的信徒，准备为击败它们领主的敌人而牺牲。当它们看到一个敌人，狂热者将点燃一个装满炸药的桶去追赶他们。爆炸越近，护甲救您性命的可能性就越小。

<span class="scroll-page">第 16 页</span>

被弃隐士是被遗忘的迷路者。一些老资格的被弃者病得太厉害，无法服侍他们的领主，不得不离开弟兄们，希望独自赢得瘟疫之神的保护。一旦出现叛徒，就意味着您可以获得骑士团的所有黑暗秘密。然而，死去的隐士不能再说话，所以您需要把他活着带到您的城堡......

<span class="scroll-page">第 17 页</span>

狂怒亵渎者是被弃骑士团的精英武士、强大的战士，从他们的狂怒和邪恶中获得力量。每个战斗都会使他们更加强大，每个伤痕都会使他们更加致命。当他们受了重伤，他们只会变得更加危险，对敌人的击打更为猛烈。然而，因为还没有人遭遇过他们，尚无人可以证实这点。

<span class="scroll-page">第 18 页</span>

瘟疫强盗是小偷、逃兵，也是失控的囚犯，逃到了瘟疫之地。他们之中许多人都是没有荣誉感的异教徒，不了解自己接受瘟疫之神的腐败而早已注定的命运。他们会为生存做任何事情，包括割断任何陌生人的喉咙。

<span class="scroll-page">第 19 页</span>

有些人认为黑暗猎人是放弃光明的流亡者，加入土匪和强盗的行列，从不幸的前同伴那里偷东西。其他人声称他们是帝国军队的前弓箭手。只有一件事是肯定的：如果你不能在混战中对抗他们，那么他们的箭就会引起严重麻烦──尤其是在你没有穿上坚的固护甲时。

<span class="scroll-page">第 20 页</span>

瘟疫野蛮人是异教部落战士，长期威胁着帝国的边界。在战斗中，这些野蛮人因为超人的力量与庞大数量而占上风。我们很幸运将他们的大军分散到卢比尼亚的北方。但即使是残存在森林与山丘中的分裂力量，仍然对任何孤独的流亡者构成致命的挑战。

<span class="scroll-page">第 21 页</span>

恐怖蝙蝠是一种野生生物，能够迅速从空中攻击疲惫的旅行者。蝙蝠会猛击它们的猎物，直到对方失去意识或失血过多。毫无疑问，这些黑暗的生物来自超自然的力量，我们尚未了解它们的真实本质，只用弩杀死了几只野兽。

<span class="scroll-page">第 22 页</span>

被咒调查官是以前的先锋骑士，曾经受命断绝了所有关系而且发了疯。他们只是为了满足对血液的渴望而杀人。尽管他们的灵魂腐败，但这些战士并没有任何战斗技能，也无所畏惧，有些人甚至可以在单一攻击后就击败骑士团的兄弟。

<span class="scroll-page">第 23 页</span>

北方之地充满着各种危险，但也会以宝贵拾物回报勇敢者。不过，总是有人更倾向于秘密的行动。其最典型的案例当然是贪财旧货商。他是一个奇奇怪怪的生物，他的样子很可恶不像人，但他的动作很快又不像麻疯病人。我们骑士团的团员只见过两次贪婪旧货商，所以我们对他的了解还是不多。贪婪旧货商态度不凶，但他还是很狡猾并实在很喜欢做那些丑陋行为，后面他背着一大袋子，里面放所有能偷到或捡到的东西。有人说，那个袋子充满着稀有的东西。不过，我们一直都赶不上旧货商，没办法为这些话获得确认。

<span class="scroll-page">第 24 页</span>

哀悼死神的影子是异界之物，曾是帝国哀悼死神骑士团的骑士。影子会吸取受害者的生命力，并可能暂时隐形且刀枪不入。他们居住在北方之地的险恶城堡废墟中。

<span class="scroll-page">第 25 页</span>

瓦格是瘟疫之神的侍僧使用炼金药水与黑暗仪式创造的一种新恐狼。这种掠食者的獠牙上滴着毒液，致命毒性在几分钟内就能杀死流亡者。

<span class="scroll-page">第 26 页</span>

维比约恩是复活的熊人。有人认为这种怪物为无名之神效力，但是它们堕落的本性令人有所怀疑。

<span class="scroll-page">第 27 页</span>

并非所有灰色死神的受害者都经过仪式埋葬。在疫情最严重的时候，尸体被毫不留情地扔进了坟墓中，没有任何仪式。谁都没想到，那么做的后果有多严重。腐烂的尸体成群聚集成无意识的怪物，攻击其中一只，肯定会出现另一只。

<span class="scroll-page">第 28 页</span>

被咒侍从是被弃骑士团司令的忠诚仆人，被剥夺了自由意志与理智，他会让敌人鲜血洒地，直到被主人下令制止。他用重物攻击，企图使对手无法动弹，阻止对方逃脱或抵抗的机会。

<span class="scroll-page">第 29 页</span>

帕雷格斯是瘟疫怪物进化的下一阶段，具有更致命的毒素与更强壮的身体。红色皮肤与难闻的气味很容易辨别。

<span class="scroll-page">第 30 页</span>

黑骑士是经验丰富的被弃勇士，经历过许多战斗。他的盔甲受到烧毁村庄的煤烟与敌人的鲜血而变得黑暗，一切杀戮都是为了瘟疫之神。

<span class="scroll-page">第 31 页</span>

瘟疫司令是被弃骑士团的军官之一，能以一挡十，进入战斗后会立刻暴怒，几乎所有对手都被撕成两半。

<span class="scroll-page">第 32 页</span>

血腥死神由这个世界之外呼唤而来的强大修博尔之灵。他的幽灵本质浸在烈士的血液中，使他有能力同时从两个世界汲取力量。血腥死神的到来是世界即将终结的第一个迹象。

<span class="scroll-page">第 33 页</span>

痛苦者是被膜拜瘟疫之神的仪式折磨的不幸俘虏。残酷的酷刑毁坏了他们的身体，粉碎了他们的心智。当痛苦者的心中除了痛苦与仇恨之外别无他物时，酷吏就会将他们释放到地下城中竞赛，让他们互相攻击或攻击不速之客。

<span class="scroll-page">第 34 页</span>

掷斧者是野蛮猎手与瘟疫之神的仆人。不要误以为他们会不顾一切嗜血。这些敌人更喜欢远程战斗，而且只要猎物还活着，就会与猎物保持一定距离。

<span class="scroll-page">第 35 页</span>

曾经是战犬骑士团的骑士，屠宰者现在成为了杀戮机器。受到杀戮欲望的驱使，受害者的尖叫声对他们来说是美妙的乐音。少数与这些瘟疫之神的仆人相遇而生还的人说，他们的主人已赐予了他们永生。

<span class="scroll-page">第 36 页</span>

与女巫不同，女祭司从小就接受训练，为瘟疫之神效命。在她们的家乡，野蛮人之地，她们被尊称为预言者。她们将神的旨意传达给被选中的战士，预言他们未来道路上的壮举、荣耀和财富。女祭司自己也会参加战斗，向对手发射如雨的毒镖。为此，她们尽量与敌人保持安全距离。

<span class="scroll-page">第 37 页</span>

酷吏是从前著名的战犬骑士团的强大士兵。血腥的仪式扭曲了他们的思想，也赋予了他们巨大的力量。为了变得更加强大，酷吏们不仅会残害敌人，还会残害盟友。虽然他们的愤怒看似自我毁灭，但不要指望轻松获胜。在战场上，一个酷吏胜过十几个普通骑士。

<span class="scroll-page">第 38 页</span>

芬里尔是看守者的新恐狼。这只野兽受训追踪被瘟疫之神标记的流亡者。如果你决定要对峙芬里尔，一定要警惕，它的利爪和獠牙含有致命毒素。

<span class="scroll-page">第 39 页</span>

群生首领是混乱的可怕爪牙，几乎被疯狂吞噬。据说，他们曾是流亡者，最终死于瘟疫。单看外观很难辨识——诅咒抹去了这些生物曾有的样貌。群生首领比其他敌人更聪明，更凶狠，有一群听从其号令的被咒者。

<span class="scroll-page">第 40 页</span>

召唤师懂得一些几乎被遗忘的野蛮人语言，这些话语会把最可怕的力量带到这个世界。他举行血腥仪式，将被诅咒者的灵魂碎片聚在一起，让这些受瘟疫感染的生物服从于同一个意志。他听从祭司的命令来收集材料，为被咒者军队制造首领，以永远效忠于瘟疫之神。

<span class="scroll-page">第 41 页</span>

瘟疫祭司塔哈尔被誉为北部最危险的祭司之一。对于崇拜瘟疫之神的野蛮人，他是领主、司令和先知。当塔哈尔到达卢比尼亚时，怪物袭击变得更加频繁有序，现在尸体和损毁房屋在我们的土地上越来越普遍。

<span class="scroll-page">第 42 页</span>

猎头者是狡猾而谨慎的敌人。只有野蛮人部落中最有经验的战士，在证明了自己追踪和控制两条腿的猎物的技能后，才会被授予这个荣誉称号。

<span class="scroll-page">第 43 页</span>

酷吏侦察员是他们部落的眼睛。他们观察营地周围发生的一切，并通知祭司。但这并不表示他们在遇到敌人、可以为自己赢得荣耀时会犹豫不决。

<span class="scroll-page">第 44 页</span>

向瘟疫之神献上无数受害者的行刑者赢得了祝福，成为了惩罚者，给弱者带来厄运。他们不惧怕死亡，因为重生只会让他们更强大。

<span class="scroll-page">第 45 页</span>

酷吏就像痛苦制造机，但残忍酷吏将低等生物的痛苦提升到了新的高度。当他战斗时，他每受到一次伤害就会变得更加愤怒，他的每一次打击都会削弱抵抗的意志，即使最崇高的敌人也无法抵抗。

<span class="scroll-page">第 46 页</span>

火焰守卫是在酷吏的房间里创造的一种生物。它曾经是人类，但现在已经不记得了。它对所有生物怀有难以估量的愤怒，而它的天然护甲的耐久性意味着它可以无视普通武器的攻击。只有寒冷才会对它造成重大伤害。
